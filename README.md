# עדי לוי · תיק עבודות

אתר סטטי — בלי build, בלי תלויות.

## העלאה ל-GitHub Pages
1. צרו repository חדש והעלו את **כל התוכן של התיקייה הזו** (index.html, images/, favicon.svg, .nojekyll) לשורש.
2. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save.
3. אחרי דקה האתר זמין בכתובת `https://<username>.github.io/<repo>/`.

## עריכה
הכול בתוך `index.html`, בראש ה-`<script>`:
- `WHATSAPP` — מספר וואטסאפ בפורמט בינלאומי (לדוגמה `972501234567`).
- `DATA` — קטגוריות ופריטים: `[שם, בד, תיאור, [תמונות]]` (משמש לתצוגה המוגדלת).
- הכרטיסים עצמם כתובים ב-HTML בתוך `<main>` — שינוי שם או בד צריך להיעשות בשני המקומות.

## הוספת תמונה
שמרו שתי גרסאות באותו שם:
- `images/thumb/NAME.jpg` — כ-720px בצד הארוך (לכרטיסים)
- `images/full/NAME.jpg` — כ-1600px בצד הארוך (לתצוגה מוגדלת)

ואז הוסיפו `'NAME'` לרשימת התמונות של הפריט ב-`DATA` (ואם זו תמונה ראשית של פריט חדש — גם כרטיס ב-`<main>`).
